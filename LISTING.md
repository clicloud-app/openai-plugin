**Description (longDescription):** CLI is app hosting run by AI agents. With this plugin, the model can deploy a GitHub repository, add a Postgres or MySQL database and connect it, set non-secret variables, read logs and metrics, roll back a bad deploy, manage domains and backups, and check whether an app is ready for real traffic. You choose which projects it can use and how much it may spend a day when you connect it; changes past that limit wait for your approval. Every change is recorded in CLI's activity log, and most can be undone. Secrets and payments stay in the CLI dashboard.

**Starter prompts (defaultPrompt, 3 × 128):**
1. Deploy my GitHub repo with a Postgres database
2. Why did my last deploy fail?
3. What am I spending and how can I cut it?

## Review notes

CLI supports card, x402 and crypto payments in its own app. This plugin does not start payments, sell credits or link to checkout or the billing page: tools that move money are not exposed, the server refuses money and selling routes for connector sign-ins, and out-of-credit errors only explain that the project needs more credit. Secrets are not accepted through tool inputs; tools return a link to the variables page instead. The plugin has no command execution: no shell, no sandboxes, no creating or running scheduled jobs and no start commands. Tools have no free-text intent field; changes are recorded in CLI's activity log as made through the connector. The email scope is optional, shown on the approval screen when requested, and userinfo returns an email only for grants with that scope. `destructiveHint` is true for deletes, restores, rollbacks, replacing the running version, overwriting variables and renames; creating things is reversible. `openWorldHint` is true for tools that reach outside the user's account (sending email, load tests, browser checks, domain search, imports, AI chat, deploying from public repositories, replaying requests).

## Reviewer sign-in

Set `CLI_REVIEWER_LOGINS` (`npx tsx scripts/reviewer-password.ts '<password>'`), seed the account with `scripts/seed-reviewer.ts`, and give reviewers the email and password in the portal's secure form. They sign in at the dashboard's sign-in page under "Reviewer sign-in".
